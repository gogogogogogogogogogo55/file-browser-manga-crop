# File Browser Manga Auto Crop

自前でホストしている **File Browser** 上で漫画画像を表示する際、余計な余白（白余白・スキャン黒枠・黒ベタ）を自動判別し、Canvas APIで高精度かつ瞬時にトリミング表示するUserscript（Tampermonkey向け）です。

---

## 💡 特徴・仕組み

- **白・黒背景デュアル自動判別**:
  画像の四辺から真の背景色を自動サンプリング。一般的な白余白だけでなく、黒枠・黒ベタのページも自動で判別して適切な切り取りを行います。
- **モルフォロジー演算（収縮）によるノイズ除去**:
  スキャナー特有の縦筋ノイズや端の斑点ゴミに引っ張られず、正確なコンテンツ領域（コマ）のみを検出します。
- **完全非破壊・クライアントサイド処理**:
  サーバー上の元画像ファイルは一切改変しません。ブラウザのHTML5 Canvas上でレンダリングするため安全です。
- **軽量・高速動作**:
  解析時のみ一時的に縮小処理を行うため、スマートフォン（Android Firefox等）でも低負荷・軽快に動作します。

---

## 📱 動作確認環境

- **ブラウザ**: Firefox for Android / 各種PCブラウザ（Chrome, Firefox, Brave, Edge）
- **拡張機能**: [Tampermonkey](https://tampermonkey.net/)
- **対象サーバー**: [File Browser](https://filebrowser.org/) 等の画像表示WebUI

---

## 🚀 インストール & 導入手順

### 1. Userscriptの追加
1. ブラウザに **Tampermonkey** 拡張機能をインストールします。
2. 本リポジトリの `Manga-Auto-Crop.user.js`を開いてスクリプトをインストールします。

### 2. 動作対象URL（@match）の変更 【重要】
初期設定ではサンプルURLが指定されています。下記の１、２を参考にご自身のFile Browser環境のURLに合わせて書き換えてください。

1. Tampermonkeyの管理画面から本スクリプトを開きます。
2. スクリプト先頭の `@match` 部分をご自身のドメインに変更して保存します。

```javascript
// ==UserScript==
// @name         File Browser Manga Auto Crop
// ...
// @match        https://files.your-domain.com/*   <-- ご自身のURLに変更
// ...
// ==/UserScript==
```
3. 画像の閲覧
File Browserで漫画画像の入ったフォルダを開き、画像を表示すると自動的に余白がトリミングされて全画面で見やすく表示されます。

⚙️ 主な設定パラメータ
スクリプト先頭の定数（パラメータ）をお好みに応じてカスタマイズ可能です。


| パラメータ名 | デフォルト値 | 説明・調整の目安 |
| :--- | :--- | :--- |
| `ANALYZE_WIDTH` | `480` | 解析用の縮小幅(px)。値を上げると精度が上がりますが処理が重くなります。 |
| `COLOR_TOLERANCE_WHITE` | `36` | 白背景判定時の色差許容値。余白が残る場合は上げ、絵が削れる場合は下げます。 |
| `BLACK_BG_MAX_LUM` | `50` | 黒背景判定時の暗部閾値。 |
| `ERODE_RADIUS` | `2` | ゴミ・スキャン線を消滅させる収縮半径(px)。 |
| `KEEP_PADDING` | `1` | トリミング後にコマの周囲に残す余白マージン(px)。 |
| `MIN_TRIM_RATIO` | `0.005` | 最低トリミング率（0.5%未満の変化は処理をスキップして高速化）。 |
